# holidays_tracker_ws

API de ejemplo **Hola Mundo** creada con Node.js y Fastify.

## Requisitos

- Node.js 20 o superior
- npm

## Instalación y ejecución

```bash
npm install
npm start
```

La API queda disponible en `http://localhost:3000`. Para cambiar el puerto, define la variable de entorno `PORT`.

## Endpoint

- `GET /` — responde con `{"message":"¡Hola, mundo!"}`.

Para desarrollo con reinicio automático al cambiar archivos:

```bash
npm run dev
```
